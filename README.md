# Device-Setting-Storage
Storing setting information in a Python powered embedded device
## Light Device
The device folder contains a working remote controlled light that you can control from your browser. It comprises:

* The code.py file containing the application
* The index.html file served by the application that allows the light colour to be set
* The boot.py file which removes usb drive support on CircuitPython devices
* The device_configurator.py file which contains the DeviceConfigurator class
* The lib folder containing CircuitPython 9.n versions of the library files used by the application

Copy the contents of this folder onto the root of a CircuitPython device to create a remote controlled light. 

## Web Editor

The web editor folder contains the settings editor web page. Use this to connect to a device via USB and update device settings. 

## Case

The case folder contains STL files for 1x3 and 2x3 8x8 pixel array lights. It uses panels which are 66x66mm in size.
